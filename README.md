## 自测与对答案

每篇主干笔记（76 篇）末尾都有两节配套内容：

1. **自检问题**：6~10 条 `- [ ]` 自测项，读完先自己回答，能答出来才算真懂。
2. **自检问题参考答案**：紧跟在后的折叠块（`> [!success]-`），**点开才显示答案**——先自己说一遍再对照，比直接读答案有效得多。

全库共 **589 条**自检项与一一对应的答案，答案都落在该篇的公式、表格、阈值上，不是泛泛而谈。

## 快速开始

1. 安装 [Obsidian](https://obsidian.md)。
2. 「打开文件夹作为仓库」，选择本仓库根目录。
3. 从 [README 从这里开始.md](README%20从这里开始.md) 进入，或直接打开 `00-总览/技能栈总览 MOC.md`。

> 本库使用 Obsidian 双链语法（`[[文件名]]`），**在 GitHub 网页上不会渲染成可点击链接**，需要在 Obsidian 中打开才能获得完整跳转与关系图体验。

## 维护约定

- 所有笔记遵循 `90-模板/写作规范.md`：统一 frontmatter、名词表、决策点、常见坑、自检问题等结构。
- 新增/修改笔记时，`## 自检问题参考答案` 紧跟在 `## 自检问题` 之后、`## 相关笔记` 之前；答案里不要新增 `[[ ]]` 双链。
- 新增笔记必须使用白名单内的文件名做双链，避免出现灰链。
- 新增排错经验用 `90-模板/排错记录模板.md`，新项目复盘用 `90-模板/项目复盘模板.md`。
